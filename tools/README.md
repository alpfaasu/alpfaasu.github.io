# tools

You do not need to open anything in here. The double-click buttons in the
main folder run these for you.

| | |
| --- | --- |
| `build.py` | Crops and shrinks photos. Run by **Update Photos.command**. |
| `build_share.py` | Packs the whole site into one file. Run by **Publish Changes.command**. |
| `offline-copy/` | The entire website as a single HTML file with the images baked in. Email it as an attachment, or keep it as a copy that works with no internet and no GitHub. |

Both scripts expect to live in this folder and look one level up for the site.
Moving them will break the buttons.
